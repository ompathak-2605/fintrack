# FinTrack — Personal & Group Expense Manager

A full-stack expense tracking system built with Spring Boot and PostgreSQL.
Built as a learning project while studying Java and Spring Boot.

## Tech Stack
- Java 24
- Spring Boot 4.0.7
- PostgreSQL 18.4
- Maven

## How to run locally
1. Clone the repository
2. Create a PostgreSQL database called `fintrack_db`
3. Copy `application.properties.example` to `application.properties`
4. Fill in your PostgreSQL password
5. Run `FintrackApplication.java`
